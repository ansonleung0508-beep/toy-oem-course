# 電子機構軟綿玩具 OEM 課程

Anson's interactive toy OEM course, written in Traditional Chinese.

This is a static site for self-study: electronics first, then mechanisms, then plush and costume, then the rest of the OEM path. Progress is stored in the browser. Open `index.html` locally, or use the GitHub Pages site.

Live site: https://ansonleung0508-beep.github.io/toy-oem-course/
